# 極速下單｜手機網購競速遊戲 v1.0

可直接放在 **GitHub Pages** 的純前端 PWA，無需付費 API、Node.js 或資料庫。

## 功能
- 手機直式介面，首頁 → 三種便利貼難度 → 五樣隨機商品任務 → 網購 → 結帳 → 結果。
- 三種難度統一 5 樣商品；差別在廣告、盜版、假官方、近似規格商品與彈窗頻率。
- 正版有多間賣場；假官方有相似店名但沒有真正的「平台認證」。
- 商品頁、評分、文字評論、附照片評論、篩選低評分／有照片。
- 購物車可增減數量，結帳前可修改任何項目。
- 任務單可從畫面邊緣打開，挑戰期間計時不中斷。
- 結帳送出後核對品牌商品、規格、真偽、數量及虛構姓名、電話、地址與付款卡資料。有錯立即失敗，不留紀錄。
- 成功時記錄百分之一秒精度的完成時間，展示與最低價同規格正版的價差明細。
- 成功紀錄儲存在本機 localStorage。**沒有雲端排行、沒有傳送姓名卡號、沒有真實付款。**
- PWA：可加入手機主畫面；首次在線開啟後，所需檔案可快取離線遊玩。

## GitHub Pages 部署
1. 建立一個新公開 repository（例如 `speedmart-game`）。
2. **將本 ZIP 解壓縮後的全部檔案與 `assets` 資料夾**上傳到 repository 根目錄。請勿只上傳 ZIP。
3. 進入 Settings → Pages → Build and deployment，選 Deploy from a branch、`main`、`/(root)`，儲存。
4. 開啟 `https://你的帳號.github.io/speedmart-game/`。手機 Safari 或 Chrome 都能玩。
5. iPhone 使用 Safari 分享選單的「加入主畫面」，Android 可由瀏覽器選單安裝或加入主畫面。

## 本地測試
在遊戲資料夾執行 `python -m http.server 8000`，開啟 `http://localhost:8000/`。直接開 `index.html` 也能運行大部分功能，但 PWA 離線快取需使用 HTTP/HTTPS。

## 改造方式
- `app.js` 的 `PRODUCTS`：更換商品資料、價格、規格與盜版名稱。
- `app.js` 的 `PEOPLE`：更換虛構聯絡資訊與測試卡。
- `app.js` 的 `DIFF`：更改難度與彈窗頻率。
- `styles.css`：修改色彩與手機 UI。
- `assets/prod-*.svg`：商品插圖（可換成已取得使用授權的真實圖片）。

注意：遊戲中品牌、評論、購物地址和卡號皆為虛構。本程式只有前端驗證，若日後要做公開排行榜，需使用可信任後端驗證挑戰，否則容易竄改成績。
