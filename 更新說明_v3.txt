極速下單 v3｜僅更新檔

從 v2 更新方法：
1. 下載並解壓縮這份 ZIP。
2. 上傳內容至你的 GitHub 專案「根目錄」，覆蓋 app.js、styles.css、sw.js，並合併 assets 資料夾內新增的圖檔。
3. 不要整個刪掉原本的 assets 資料夾：有些舊圖檔仍然會被使用。
4. GitHub Pages 更新後，手機請完整關掉網頁再重開一次；必要時重新整理或清除網站快取。

這份 ZIP 不是完整遊戲，必須在既有 v2 專案上使用。

更新內容：
- 基礎商品從 16 種擴到 32 種，每局仍抽 3 件。
- 新增新商品圖片與評論圖片；假貨商品採用不同圖檔，方便結帳後比較。
- 結帳失敗顯示實際購買與同規格正版最低價的對照、真假線索、錯誤規格、缺件及多買商品。
- 瘋狂模式新增 10 種形式不同的模擬廣告：小券、全螢幕影片、浮動直播、優惠券雨、問卷、轉盤、底部滑出、長按刮刮樂、跑動 X、頂端布條。
- 部分廣告可能連鎖出現；低機率觸發三關連續的廣告 BOSS。
- 仍使用虛構品牌、聯絡資料與遊戲卡號，不會有真實付款或廣告連線。

註：新商品主圖為自行製作的仿電商商品插畫，不是實際品牌攝影照片。
